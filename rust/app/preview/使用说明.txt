模仿者小工具 Rust 预览 11月 v2 —— 使用说明

这是新版（Rust 重写）的试用版，和你现在用的模仿者小工具是两个独立的程序。

一、怎么拿到
1. 打开 GitHub 上这次构建的 Actions 页面，在页面最下面的 Artifacts 里点「模仿者小工具 Rust 预览 11月 v2」，下载 zip。
2. 把 zip 解压到任意文件夹（桌面、D 盘都行）。

二、怎么用
1. 先关掉旧的模仿者小工具（右下角托盘图标右键 → 退出）。两个程序用同一组快捷键，同时开会抢快捷键。
2. 双击「模仿者小工具 Rust 预览 11月 v2.exe」。
3. 如果 Windows 弹出「Windows 已保护你的电脑」：这是因为这个预览版没有签名。点「更多信息」，再点「仍要运行」。

三、你的名单
- 预览版有自己的数据，不会改动旧版的名单和设置。
- 第一次打开时，它会把旧版的全部内容复制一份过来：黑名单、嘉宾、组合、记录、设置、快捷键、主题和你加的声音。只复制这一次。
- 之后在预览版里改的东西，旧版看不到；在旧版里改的，预览版也看不到。
- 预览版不会检查更新，也不会开机自动启动。

四、不想用了
1. 关掉预览版（托盘图标右键 → 退出）。
2. 删掉解压出来的文件夹。
3. 想把预览版的数据也删干净：在地址栏输入 %APPDATA%\BlackListDetect-RustPreview 回车，删掉这个文件夹。
   注意不要删 %APPDATA%\BlackListDetect，那是旧版的名单。

旧版照常可以用，随时打开就行。
